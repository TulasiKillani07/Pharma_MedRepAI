## Optional Enhancements for Better Swagger Docs

### 1. CME Schemas (`cme/schemas.py`)
**Current:** Plain strings
```python
event_mode: str  # "online" or "offline"
status: str  # "upcoming", "completed", etc.
```

**Better:** Use Enums from model
```python
from app.models.cme_model import CMEEventMode, CMEEventStatus, CMEPlatform

event_mode: CMEEventMode
status: CMEEventStatus = CMEEventStatus.UPCOMING
platform: Optional[CMEPlatform] = None
```

**Benefit:** Swagger shows dropdown with valid values

## Why This is Optional

### Pros of Adding Enums to Schemas:
- ✅ Better Swagger documentation
- ✅ Dropdown menus in Swagger UI
- ✅ Clear valid values for API consumers
- ✅ Consistent with internal models

### Cons/Considerations:
- ⚠️ Requires importing enums from models into schemas
- ⚠️ Slight coupling between API layer and model layer
- ⚠️ Not necessary for functionality (already validated in service)
- ⚠️ More imports to manage

## Recommendation

**For now: Leave as-is** ✅
- API is functional
- Validation happens in service layer
- Documentation strings explain valid values

**Future enhancement:**
- Add enums to schemas when updating API documentation
- Do it incrementally per feature as needed
- Prioritize features with many enum values (CME, Notifications)

## Implementation Example

If you decide to add enums to CME schemas:

```python
# backend/app/api/v1/cme/schemas.py

from pydantic import BaseModel, Field
from typing import Optional
from datetime import date
from app.models.cme_model import CMEEventMode, CMEEventStatus, CMEPlatform

class CMEEventCreate(BaseModel):
    title: str = Field(..., min_length=1, max_length=200)
    description: Optional[str] = Field(None, max_length=2000)
    event_date: date
    event_time: str
    event_type: str
    max_attendees: Optional[int] = None
    
    # ✅ Use enums for better Swagger docs
    event_mode: CMEEventMode
    platform: Optional[CMEPlatform] = None
    platform_name: Optional[str] = None
    meeting_link: Optional[str] = None
    venue_name: Optional[str] = None
    address: Optional[str] = None
    
    speaker: str
    status: CMEEventStatus = CMEEventStatus.UPCOMING
```

Then Swagger will show:
- `event_mode`: Dropdown with "online" | "offline"
- `status`: Dropdown with "upcoming" | "completed" | "cancelled" | "rescheduled"
- `platform`: Dropdown with "Zoom" | "Teams" | "Google Meet" | "Other"

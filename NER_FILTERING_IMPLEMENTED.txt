🛡️ FILTERS IMPLEMENTED:
================================================================================

FILTER 1: Noise Word Blacklist
-------------------------------
Removes common non-medical words that model incorrectly labels:
- Question words: what, when, where, why, how
- Common verbs: is, are, was, were, be, been
- Pronouns: I, you, he, she, it, this, that
- Prepositions: in, on, at, to, for, with
- Articles: a, an, the
- Question fragments: causing, related, worried, noticed

❌ BEFORE: "what could be causing this?" → DISEASE
✅ AFTER: Filtered out (not medical)


FILTER 2: Single Character Filter
----------------------------------
Removes single characters (except valid ones like vitamin names)

❌ BEFORE: "," → DISEASE
✅ AFTER: Filtered out


FILTER 3: Punctuation Filter
-----------------------------
Removes pure punctuation marks

❌ BEFORE: "?" → DISEASE
✅ AFTER: Filtered out


FILTER 4: Question Fragment Filter
-----------------------------------
Removes question-related phrases using regex patterns

❌ BEFORE: "could this be serious?" → DISEASE
✅ AFTER: Filtered out


FILTER 5: Medical Term Validation
----------------------------------
Validates against whitelists of known symptoms and diseases

KNOWN SYMPTOMS (40+ terms):
- fever, headache, cough, pain, nausea, vomiting, diarrhea
- fatigue, weakness, dizziness, chills, sweating, itching
- frequent urination, thirst, dry mouth, etc.

KNOWN INDICATIONS (50+ diseases):
- diabetes, hypertension, asthma, copd, arthritis
- migraine, epilepsy, cancer, tuberculosis, etc.

✅ "frequent urination" → SYMPTOM (validated)
✅ "thirst" → SYMPTOM (validated)
❌ "been high" → Filtered out (not in whitelist)


FILTER 6: Length Validation
----------------------------
- Symptoms: Max 5 words
- Diseases: Max 6 words
- Minimum: 3 characters

❌ BEFORE: "headaches almost daily with sensitivity to light" → DISEASE
✅ AFTER: Filtered out (too long)


FILTER 7: Text Cleaning
-----------------------
Removes extra words and normalizes text:
- Removes leading/trailing articles (a, an, the)
- Removes question marks and exclamation points
- Removes extra whitespace

❌ BEFORE: "the fever ?"
✅ AFTER: "fever"


================================================================================
📊 HOW IT WORKS:
================================================================================

FLOW:
1. User query → NER API (external model)
2. NER API returns entities (with errors)
3. Backend filters each entity:
   ✓ Is it a noise word? → Remove
   ✓ Is it punctuation? → Remove
   ✓ Is it a question fragment? → Remove
   ✓ Is it a known medical term? → Keep
   ✓ Is it too long/short? → Remove
4. Clean entities → Drug search


EXAMPLE:
--------
User Query: "I have fever, headache and been worried about diabetes, what could be causing this?"

NER API Returns (with errors):
- "fever" → SYMPTOM ✅
- "headache" → SYMPTOM ✅
- "been worried" → DISEASE ❌
- "diabetes" → INDICATION ✅
- "what could be causing this" → DISEASE ❌

After Filtering:
- "fever" → SYMPTOM ✅ (validated)
- "headache" → SYMPTOM ✅ (validated)
- "diabetes" → INDICATION ✅ (validated)

Final Result:
symptoms: ["fever", "headache"]
indications: ["diabetes"]


================================================================================
⚠️ LIMITATIONS:
================================================================================

1. WHITELIST COVERAGE
   - Only 40+ symptoms and 50+ diseases in whitelist
   - Rare medical terms may be filtered out
   - Solution: Expand whitelist over time

2. COMPOUND TERMS
   - "severe headache" → Validated (contains "headache")
   - "type 2 diabetes" → Validated (contains "diabetes")
   - Works for common compounds

3. TYPOS
   - "fevr" → Filtered out (not in whitelist)
   - Solution: Add fuzzy matching in future

4. NEW MEDICAL TERMS
   - Model may learn new terms not in whitelist
   - Solution: Regularly update whitelist

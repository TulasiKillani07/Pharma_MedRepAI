STEP 2: Configure Gmail App Password
-------------------------------------
⚠️ IMPORTANT: You CANNOT use your regular Gmail password!

1. Go to your Gmail account: proxzaraisolutions@gmail.com

2. Enable 2-Factor Authentication:
   - Go to: https://myaccount.google.com/security
   - Click "2-Step Verification"
   - Follow the setup process

3. Generate App Password:
   - Go to: https://myaccount.google.com/apppasswords
   - Select "Mail" as the app
   - Select "Other" as the device
   - Name it: "MedRep Backend"
   - Click "Generate"
   - Copy the 16-character password (e.g., "abcd efgh ijkl mnop")

4. Add to .env file (remove spaces from app password):
   
   SMTP_USER=proxzaraisolutions@gmail.com
   SMTP_PASSWORD=abcdefghijklmnop
   SMTP_FROM_EMAIL=proxzaraisolutions@gmail.com
   SMTP_FROM_NAME=MedRep Platform
   FRONTEND_URL=http://localhost:3000

📧 HOW IT WORKS:
================================================================================

SINGLE USER CREATION:
---------------------
1. Admin creates a doctor/MR via POST /api/v1/doctors or /api/v1/mrs
2. System generates a strong random password (12 characters)
3. Password is hashed and stored in database
4. Invitation email is sent to the user with:
   - Welcome message
   - Login credentials (email + temporary password)
   - Login link to frontend
   - Security notice to change password

================================================================================
🐛 TROUBLESHOOTING:
================================================================================

ERROR: "Username and Password not accepted"
SOLUTION: You're using regular password instead of App Password
          Follow Step 2 above to generate App Password

ERROR: "SMTPAuthenticationError"
SOLUTION: Check that 2FA is enabled and App Password is correct

ERROR: "Connection refused"
SOLUTION: Check SMTP_HOST and SMTP_PORT in .env file

ERROR: "Email not received"
SOLUTION: 
- Check spam/junk folder
- Verify recipient email is correct
- Check backend logs for email sending errors
